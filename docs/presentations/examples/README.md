# Fictional weekly presentation example

The five JSON fixtures form one coherent example: Example Company brand kit, a six-layout curated template, a six-slide weekly deck, a saved draft-only series and a generation manifest. All company/user/source/asset IDs and numbers are fictional. No actual logo, PowerPoint file, render, review receipt, schedule or delivery is included.

The deck demonstrates editable text, a native column chart, a native table and a native system flow with stable object IDs, plus claims/citations and notes. The 21–27 September 2026 reporting week is expressed as a Europe/Rome calendar week with UTC boundaries. Daily counts `4 + 5 + 3 + 6 + 7 = 25` are illustrative fixture data; there is no supplied prior-week comparison.
